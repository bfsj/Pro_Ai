# RTX 4090 动态 KV Cache 配对实验

[三精度对照实验：FP32、FP16、BF16 各 100 组](precision-comparison.md)。下文保留此前 208 组 FP32 的结果。

Qwen3-0.6B、FP32、SDPA、Torch RMSNorm。8 种工作负载各用 26 组不同种子的合成输入，共 208 个输入批次。每批分别执行动态缓存及完整前缀重算，生成 32 个 token。两条路径的 token 序列在 208/208 批次完全相同。测速前预热，交替平衡两种执行顺序，计时边界同步 CUDA，计入整段生成耗时。

| Batch | 输入长度 | 完整前缀重算 tokens/s | 动态缓存 tokens/s | 配对加速比中位数 |
|---:|---:|---:|---:|---:|
| 1 | 128 | 37.53 | 44.84 | 1.19× |
| 1 | 256 | 37.75 | 44.93 | 1.19× |
| 1 | 512 | 32.40 | 44.89 | 1.38× |
| 1 | 1024 | 18.58 | 44.26 | 2.36× |
| 4 | 128 | 146.49 | 175.38 | 1.17× |
| 4 | 256 | 90.61 | 174.07 | 1.92× |
| 4 | 512 | 46.47 | 171.41 | 3.69× |
| 4 | 1024 | 21.45 | 147.25 | 6.87× |

吞吐两列各自取中位数；最后一列先计算每批配对比值再取中位数。B=4、输入 1024 的 26 个比值范围为 4.91–6.95×。基线是每个 decode 步骤重算完整前缀。单卡合成负载，结果随请求形状变化。

CPU/FP32 另测 208 条唯一提示词（32 条手写，11 个任务模板各 16 条），每条生成 16 个 token。动态和静态缓存各自与原生 Transformers 贪心生成 208/208 条完全一致。此项检查生成路径一致性，未评估回答质量。
